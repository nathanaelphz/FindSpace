# SpaceLens

Static site (HTML + CSS + JS). No build step.

## Run locally
Open `index.html`, or use the VS Code Live Server extension.

## Deploy to Vercel
1. Push this folder to GitHub.
2. Vercel > Add New > Project > import the repo.
3. Framework Preset: Other. Build command: empty. Output directory: empty (or `.`).
4. Deploy.

Prototype data is simulated (timetables, capacities, library occupancy).
